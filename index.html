Offline POS • C# .NET & SQLite Enterprise System

Retail POS: Hybrid Cloud Architecture & Dual-DB Sync

GitHub Repo

Industrial-grade desktop Point of Sale (POS) system engineered for high-availability retail terminals with unpredictable WAN connectivity. Designed around an N-Tier C# architecture implementing an Offline-First persistence strategy: all ledger operations execute against an embedded zero-latency SQLite database, reconciled with a remote PostgreSQL cluster on Neon.tech via background two-way conflict-resolution workers. Implements SHA-256 integrity checks with BouncyCastle and automated invoice generation with iText7.
