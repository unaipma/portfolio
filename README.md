## 🚀 Featured Projects

### 1. CryptoDash: AI-Powered Financial Intelligence
- **Stack**: Next.js 15 (App Router), TypeScript, Google Gemini 2.5 Flash, TailwindCSS / CSS, Recharts, CoinGecko API.
- **Highlights**: Direct integration with Gemini 2.5 Flash via secure Next.js Server Actions for automated Buy/Hold/Sell signals. Aggressive client-side caching to respect CoinGecko API rate limits, minimal bundle footprint with React Server Components.
- **Repository**: [github.com/unaipma/cryptodash](https://github.com/unaipma/cryptodash)

### 2. Triptoyou: Distributed Travel Management System
- **Stack**: Angular (SPA on Vercel), Laravel REST API (Railway), PostgreSQL (Neon.tech), Stripe Checkout, Google Gemini AI.
- **Highlights**: Decoupled microservice-inspired architecture. Laravel Sanctum tokenized authentication, asynchronous queue workers for transactional emails and PDF vouchers, live Stripe Checkout webhooks, and embedded Gemini assistant.
- **Repository**: [github.com/unaipma/triptoyou](https://github.com/unaipma/triptoyou)

### 3. Retail POS: Hybrid Cloud Architecture & Dual-DB Sync
- **Stack**: C# (.NET), SQLite Local, PostgreSQL Remote (Neon.tech), BouncyCastle (SHA-256), iText7.
- **Highlights**: N-Tier industrial desktop POS designed for unstable WAN retail environments. Offline-First persistence strategy with zero-latency local SQLite operations and two-way background conflict-resolution sync with cloud Postgres. Cryptographic audit integrity and automated invoice generation.
- **Repository**: [github.com/unaipma/pos](https://github.com/unaipma/pos)
